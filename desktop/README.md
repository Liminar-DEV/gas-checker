# Gas Checker (desktop)

**TL;DR (English).** Read-only Windows checker for Minecraft screenshare (SS) checks: it scans local drives, Java
process memory and traces of program runs for known cheats. The result is posted to a public ntfy.sh topic derived
from a 12-character code that the moderator gives you. Build with `npm install && npm run build`. The detection
rules are kept encrypted; a build without the key has only a partial open rule set. Anyone who knows the code can
read the topic, and file paths may contain your Windows user name.

## Что это

Чекер для проверок (SS) игроков Minecraft. Сканирует ПК **только на чтение**, показывает вердикт в окне и отправляет
результат модератору через публичный сервис [ntfy.sh](https://ntfy.sh) по 12-символьному коду проверки.

## Что сканирует

- **Файлы:** все фиксированные диски (сетевые и съёмные пропускаются), содержимое `.jar`-архивов и другие файлы.
- **Память:** процессы, которые есть смысл проверить. Только чтение.
- **Следы запусков:** журналы и кеши Windows, запущенные процессы.
- При старте скана чекер скачивает SS-утилиты с официальных источников (Everything, JournalTrace, Shellbag Analyzer)
  в новую папку со случайным именем `%TEMP%\GasCheckerTools-…` (доступ только у Администраторов и SYSTEM) и открывает их;
  хеши Everything и JournalTrace проверяются, Shellbag Analyzer без проверки хеша; строку поиска для Everything кладёт в буфер обмена.

Что именно и как ищется, здесь не описано: правила детекта лежат в зашифрованном файле, см.
[src-tauri/rules/README.md](src-tauri/rules/README.md). Открытая часть правил ловит только клиенты с
публичным исходным кодом.

## Как собрать

Нужны Node.js, Rust (stable-msvc), MSVC Build Tools и WebView2 (есть в Windows 10/11).

```bash
npm install && npm run build
```

Результат: `src-tauri/target/release/gas-checker.exe`. Тесты: `cd src-tauri && cargo test`.

Без переменной окружения `GASCHECKER_RULES_KEY` сборка идёт с открытыми правилами (при компиляции видно
предупреждение, а в окне программы заметка). С ключом и файлом `src-tauri/rules/rules_private.rs.enc`
подключаются полные правила. Свой ntfy-сервер: переменная `GASCHECKER_NTFY_URL` при сборке (по умолчанию
`https://ntfy.sh`).

## Запуск

Запускайте `gas-checker.exe` (он запросит права администратора) и введите код от модератора. Код можно передать
аргументом: `gas-checker.exe ABCDEFGHJKMN`. Exe **не удаляет себя** при выходе.

## Почему нужен администратор

Скан памяти читает процессы, в том числе запущенные с повышенными правами; без администратора Windows не даст
их открыть. Чекер использует только чтение: ничего не пишет и не изменяет, файлы не удаляет и не распаковывает на диск.

## Ретранслятор и приватность

- Чекер отправляет результат через публичный сервис ntfy.sh: `POST https://ntfy.sh/gaschecker-<код в нижнем регистре>`,
  без аккаунта. Отправляются вердикт-данные (число проверенных JAR, находки с путями), имя ПК и ход скана.
- ntfy.sh кэширует сообщения примерно 12 часов.
- Код проверки — **единственный секрет**: любой, кто его знает, может читать и писать в этот топик. Не публикуйте код.
- Пути к файлам могут содержать имя пользователя Windows.
- Вердикт («обнаружено» / «подозрение» / «чисто») считает панель модератора по присланным находкам.
- Больше чекер никуда ничего не отправляет (кроме загрузки SS-утилит с их официальных сайтов).

Формат сообщений (одна JSON-строка, лимит ntfy 4096 байт):

```
{"v":1,"t":"hello","host":"<ИМЯ ПК>"}
{"v":1,"t":"progress","phase":"walking|checking|finalizing","checked":N,"total":M}
{"v":1,"t":"result","jars":N,"unreadable":N,"ms":N,"stalled":N,"det":[{"k":"<kind>","p":"<path>"}],"sus":[...],"more":N}
```

Пути обрезаются до 160 символов; если находок много, лишние считаются в `more`.

## Честные ограничения

- «Чисто» ничего не гарантирует: проверка ловит только то, что есть в правилах. Сборка с открытыми правилами
  ловит заметно меньше.
- Результат присылает сам клиент на ПК игрока; тот, кто знает код проверки, может подделать сообщение. Используйте
  проверку только с демонстрацией экрана.
- Платные обфусцированные клиенты и новые версии читов могут не находиться.
